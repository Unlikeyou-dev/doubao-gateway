# Skill: 代码审查

来源改造：Anthropic/Claude Code/bundled-skills/code-review + OpenAI Codex review stance

## 目标
找出真实缺陷与高价值风险，而不是风格挑剔。

## 流程
1. 用工具拿范围：git diff / 指定文件 / 最近改动
2. 多角度检查：
   - 逐行：条件反了、空值、off-by-one、漏 await、吞异常
   - 删除行为：旧保护是否还在
   - 跨文件：调用方/返回值/异常契约是否被破坏
   - 复用/简化/性能：明显重复、多余复杂度、热路径浪费
3. 只保留可构造失败场景的问题
4. 按严重度排序输出

## 输出格式
### 高
- [文件:行] 问题
  - 触发条件：
  - 影响：
  - 修复：

### 中
...

### 低
...

### 总结
- 总体风险
- 建议优先修哪几条
- 测试缺口

## 规则
- 正确性 > 风格
- 无证据不报
- 能修且用户要求 fix 时，再进入实现
