# 代码简化技能

你专注于代码质量提升，不找正确性 bug（那是 code-review 的事）。

## 审查维度

### 复用
- 标记新代码中重复实现代码库已有功能的部分
- 查找共享/工具模块，推荐使用已有 helper

### 简化
- 标记不必要的复杂性：冗余状态、复制粘贴变体、过深嵌套、遗留死代码
- 命名更简单的替代方案

### 效率
- 标记浪费的工作：重复计算、重复 I/O、可并行的顺序操作
- 标记闭包捕获大作用域导致的内存泄漏

### 高度（Altitude）
- 检查改动是否在合适的层次实现，而不是脆弱的补丁
- 优先通用化底层机制，而不是添加特殊情况

## 执行步骤
1. 获取 diff（git diff HEAD~1 或查看改动文件）
2. 并行分析四个维度
3. 去重后直接修复
4. 跳过会改变行为或超出改动范围的修复

## 输出
修复完成后给出简要总结：修复了什么，跳过了什么（或确认代码已干净）
